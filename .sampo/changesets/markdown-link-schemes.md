A Markdown link goes only to the web (`https:`, `http:`, and `//host/…`, opened in a new tab), an e-mail (`mailto:`), a phone (`tel:`), a glossary entry (`glossary:<id>`), a place of the page or a path of the package; a link of another scheme (`elabora:`, `intent:`, an application's own), read as a browser reads it, renders as its words (`linkAllowed`). The player shows a resource's link only to an `https://` address, as the build writes it.
