`elabora help` opens with a « Start here » section of commands to try, shorter command descriptions, and `elabora help <command>` for one command. Common mistakes get one clear line: an unknown command or option suggests the closest one, a folder without a course, an unknown LMS profile, an MCP folder it cannot read and a preview port already in use say what to do.
