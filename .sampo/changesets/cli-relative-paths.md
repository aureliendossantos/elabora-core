`elabora projects create --charter` takes a course folder relative to the current folder (`--charter examples/canal-locks`) as well as an absolute one or a library project id; a bare name is a project id first, then a folder of that name. `E_WEB_IMAGE` says the rule `elabora build --image` and `elabora publish --image` follow, the one the documentation gives: a path from the folder the command runs in, or an absolute one. The measure of the fit (`elabora fit`, and the fit of `elabora test`) waits up to two minutes for the player to start on a busy computer, and says what stopped it (the page's errors, the files that did not load) instead of a bare timeout.
