What the player focuses for screen readers (a screen's or a panel's heading after each change, a revealed step, the main area) no longer draws a ring when a theme puts one on everything `:focus-visible`: a learner going on with the keyboard saw the title framed on every screen. Controls keep their ring. Free-object gates: the hidden Electron window that runs them is the page's size (on macOS its title bar took the bottom 28 px off every snapshot, an object's bottom controls cut); a test whose WebGL context was lost before a snapshot (the GPU process giving way on a loaded machine) runs again instead of comparing a page without its scene, and says so with E_GATE_CONTEXT_LOST if the context is lost again.
