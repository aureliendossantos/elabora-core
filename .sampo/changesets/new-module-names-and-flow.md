A new project of the library is named `elabora-module-` and six lowercase letters and digits that cannot be misread (`elabora-module-k7m3qa`), drawn again when the library, its trash or `ELABORA_DATA_DIR` already has the name, instead of a UUID: the folder an AI app asks the author to trust reads as Elabora's. Projects made before keep their UUID folder, and both forms are project ids everywhere (`projects list`, `path`, `rename`, `trash`, `import --replace`, `elabora_projects_path`); `elabora projects` shows the six letters, which find the project again. The skill `elabora-course-authoring` now has the agent build a new course's screens right after its plan, without waiting for the plan's approval unless the author's request says to; the plan stays a draft the author validates later.
