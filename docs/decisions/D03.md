# D3. Session end without `unload`

Chrome and Edge stopped firing `unload` on 22 September 2026, and only the LMS or IT can re-enable it. The player commits after every change, on `visibilitychange: hidden` and `pagehide`, offers a Quit button, sets `cmi.core.exit = suspend` from the first second, and never re-initialises after `LMSFinish`. The emulator closes windows abruptly and checks what the LMS kept.
