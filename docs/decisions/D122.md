# D122. What a canvas page or a relay page says is read as data, and what the host posts goes to one exact origin (19 Nov 2026)

The desktop's window read what the canvas page says as it read its own code's: a message of its frame, typed by the language. A canvas page of the web is another origin, and a relay page of the frames host can be taken over by the code of a free object (D119): neither says what the type says.

Decided:
- **A message of a frame is heard only from that frame's window, at its exact origin** (`createPageCanvasHost` checks `event.source` and `event.origin` against the frame it holds, never the origin alone, nor `*`): the window of the app itself, a sibling frame and a frame of the same origin that is not the canvas's say nothing.
- **It is read, field by field, before it is used** (`@elabora/player` `canvas-parse.ts`): `parseCanvasMessage` for the canvas page (`ready`, `layout`, `navigate`, `error`, `item`, `language`, `answer`), `parseRelayToApp` for a relay page (D118), `askResultOf` for the result of a question, by the shape of the question that was asked. A number that is not finite, a list past its bound (5 000 entries), a string past its length, a field of another type is null for the message, or leaves out that part of it (a layout's texts, terms, placing or glide); what a message adds to a block is not kept. A page that answers a question with another shape answers nothing: the question is rejected.
- **Everything the host posts to a page is to one exact origin**: the canvas's for the page, the relay host's for its relay page. There is no `*` in the host.
- **What a taken-over page can make the window believe** is bounded as D119 says: a version of the relay, a route that opened or closed, a layout of the canvas it was framed as, none of which opens a file, changes a module or shows the person what the app did not.

*Revisit if:* the canvas page runs code of an author (today it runs the player's scripts only): then its messages are read as those of a relay page of the frames host are.
