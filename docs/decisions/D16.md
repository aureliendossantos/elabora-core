# D16. Media inside the package, one master per file at the high preset (6 Oct 2026)

Video, audio and images are inside the SCORM package. Imports are converted in the background to web formats (MP4 H.264/AAC, M4A, WebP; SVG unchanged); the original is never copied into the project; the master kept is the conversion at the `high` preset. `delivery.mediaQuality` (`high`, `medium`, `low`) picks the preset of a package, to fit LMS size limits; lower presets are encoded from the masters and cached. Metadata (GPS positions of phone media) is stripped. ffmpeg runs as an external program. Packages are written as streams and media are stored without recompression.
*Revisit if:* clients need streaming from a video platform (then a hosted-video block per platform), or the high preset proves visibly insufficient for screen recordings (then a lossless-ish screen preset).
