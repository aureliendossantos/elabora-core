# D75. A file written by an agent's own tools is computed from the version it most likely read (12 Nov 2026)

An agent may edit a course with its own file tools: it reads a file, thinks, and writes it with its edit, sometimes minutes later. The engine turned that write into the operations between the files as they were and the file written, so the write undid, in silence, whatever the author (or, in a project in the cloud, anyone) had changed in that file meanwhile. Rebase ([D74](D74.md)) closes this between copies only if the change says what it was computed on, and here nothing tells when the agent read.

Decided:
- **The base is the closest recent version.** For each file written, among the recent versions the copy held (the files as they are first, then older ones), the base is the version the written file is closest to: the fewest operations between them, JSON compared by value whatever the order of keys (a program that rewrote a file in another order did not change its keys). The edit is the operations from that base to what was written, rebased on the files as they are as an agent's change: what changed since and the edit did not touch is kept; where both changed, what is there now is kept and the edit's operation is reported (`externalEdit` in `@elabora/core` `sync/external.ts`).
- **As close: the oldest.** When several versions are as close, the edit rewrote what changed between them, and nothing says whether the agent saw it. The oldest is taken, so a person's edit is kept and the agent's reported: an agent's edit lost and told beats a person's lost in silence.
- **The agent is told.** `merged` lists the files whose content is no longer what was written, for the agent to read again.

Weighed:
- **The newest of the versions as close.** Rejected: the bench finds at once an agent writing a field a person changed after the agent read it, and the person's edit lost.
- **A version older than the copy keeps.** The copy keeps its recent versions (the bench, 64); an agent that writes from a file read before all of them is computed from the oldest kept.

*Revisit if:* agents tell when they read (a tool that writes with the version it read would make the base exact); the engine's versions are kept for too short a time for slow agents.
