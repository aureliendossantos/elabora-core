# D81. The schemas a course writes: the keywords the interpreter reads, and a clear refusal for the others (12 Nov 2026)

`compileInline` ([D80](D80.md)) reads the schemas that components (`props`), free-object manifests (`props.properties`) and the built-in blocks bring. It is not a general JSON Schema validator.

Decided:
- **Supported:** `type` (one or a list), `enum`, `const`, `properties`, `required`, `additionalProperties`, `patternProperties`, `propertyNames`, `unevaluatedProperties`, `minProperties`, `maxProperties`, `items`, `prefixItems`, `minItems`, `maxItems`, `uniqueItems`, `minLength`, `maxLength`, `pattern`, `format: "color"`, `minimum`, `maximum`, `exclusiveMinimum`, `exclusiveMaximum`, `multipleOf`, `allOf`, `anyOf`, `oneOf`, `not`, `if`/`then`/`else`, and `$ref` to `#/…` in the same schema. `title`, `description`, `default`, `examples`, `$comment`, `$defs`, `contentEncoding`, `contentMediaType` and every `x-*` annotation are read as annotations, as before. Other formats are ignored, as before.
- **Refused, by name:** `contains`, `minContains`, `maxContains`, `dependentRequired`, `dependentSchemas`, `dependencies`, `unevaluatedItems`, `$anchor`, `$dynamicRef`, `$dynamicAnchor`, `$recursiveRef`. A schema that uses one does not compile: the error says `keyword "contains" is not supported in Elabora schemas (supported: …)` and reaches the author where a schema that does not compile always did: `E_COMPONENT_SCHEMA` for a component, `E_SCHEMA` « Prop … schema does not compile » for a free object. A `$ref` that leaves the schema is refused as Ajv refused it.
- **A schema that Ajv refuses reads the same**: an invalid schema gives `schema is invalid: …` with Ajv's text, an unresolvable `$ref` or a regular expression that does not compile gives their errors.
- The samples and the built-in schemas use none of the refused keywords (the differential test compiles them all). A component that needs one of them says so, and the interpreter learns it with its differential cases.

Weighed:
- **Writing every keyword at once.** Rejected: nobody writes `contains` or `dependentRequired` in a prop; each would be code and cases for no reader. A refusal that names the keyword costs an author one line and no exception.
- **Ignoring the keywords it does not know**, as Ajv's non-strict mode ignores unknown ones. Rejected: a constraint that silently stops checking is worse than a message.
