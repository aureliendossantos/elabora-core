# D2. SCORM 1.2 only, one SCO, no sequencing

SCORM 2004 has no feature Stage 1 needs: Moodle and Totara do not process it, SuccessFactors documents a 4,000-character `suspend_data` in 2004 (64,000 in 1.2), and each LMS accepts different editions (see the LMS documentation behind the profiles, `profiles/*.json`). Completion and success are combined through `reportAs` (as Storyline does); interactions exist in 1.2; a single SCO needs no sequencing. The compact keyed state fits the strict 4,096 limit with a computed worst case.
*Revisit if:* a client LMS needs separate completion/success reporting, per-objective status, or more than 4,096 characters of state — then add 2004 per edition, profile by profile, and cmi5 for 360Learning and Rustici-based LMSs.
