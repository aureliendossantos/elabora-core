# D9. Executable LMS profiles

Profiles are JSON files validated by a schema; unknown values are `null` and listed in `toMeasure`. The compiler applies the strictest values of the target profiles (suspend data, size, file count, compression ratio, forbidden extensions); a course names its LMS in `delivery.lms`. With none chosen (the `unknown` profile), package limits are warnings that name the documented LMSs that would refuse the package, never errors on an assumed limit: the documented ones range from 100 MB to 4 GB; the emulator reproduces launch topologies (iframe, popup, SuccessFactors popup chain, Docebo nested iframe) and data limits on top of scorm-again.
