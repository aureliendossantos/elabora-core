# D124. A module made from a template in a browser: the template's files given to `create_course` (26 Nov 2026)

« Nouveau module » offers the module templates (D68) on the desktop and in a browser. On a computer a module from a template is a copy of its folder made the author's (`createFromTemplate`), or, in a language the template is not in, a blank module with its charter (`copyCharter`, D69): both read and write a folder. A browser has no folder, and its project starts empty in its room (D112). This revises D112, whose « Revisit if » was this case.

Decided:
- **`create_course` takes what the module starts from**, `from`, given by the browser's host: `template`, the template's files in the course's language as a copy of it is before it is made the author's (`templateCopy`: without its licence, history and builds, its translation built); or `charter`, the files the charter takes as `copyCharter` writes them and its course's theme, presentation and player. Texts come with their text, media by their hash and size. The command writes them as the first change, as D112 writes a blank module's: one change, journaled, sent, undone as any other.
- **A template's copy without a language asked keeps the template's own.**
- **The same bytes on both hosts.** What a copy changes to become the author's module (`templateTexts`: the id and title on the course, the plan and the cover, the language, the brief, AGENTS.md's notes), the note of a charter taken (`charterNote`) and the fields of course.json a charter brings (`withCharter`) are pure functions of the core, called by `createFromTemplate`, `createProject` and `copyCharter` on a computer and by the command in a browser.
- **The journal names the template, not its files** (they are in the operations): `from` is journaled as its kind, the template's id (or the charter's course) and the number of files.
- **Media the host holds are sent from it.** A browser's copy sends to the team the media a change writes that it keeps; a module from a template writes media it has never kept (the template's fonts and pictures, which the app ships by hash, `provideMedia`): the copy takes them from its host, checked against their hash, keeps them and sends them.
- **Refused before anything is written** (a room runs the command for an editor who sends it, D112: `from` is checked as anything sent): a start that is not a template's or a charter's whole, a file that is neither a text nor a medium by its hash and size, a path out of the project or under `.elabora/`, a text given for a file a project reads as bytes, or a medium for one it reads as text. A folder's `.gitignore`, which a template carries, is left out (D112).

Weighed:
- **The files written by the server when the project is made.** Rejected, as in D112: the server would carry every template, in each language.
- **A dedicated command for a template.** Rejected: a module from a template is a new module's first change, with the same rule of a project that has a course already.
- **A browser that builds a template's translation.** Rejected: the browser's host ships each template in each of its languages, built once from the same core.

*Revisit if:* a browser makes a module from another module's charter (D69).
