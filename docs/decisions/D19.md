# D19. A project library managed by the app, and project archives (6 Oct 2026)

The app keeps projects in its own library and people exchange project archives, as DaVinci Resolve does, rather than editing folders anywhere on disk. It gives control over where projects live (never in OneDrive- or iCloud-synced Documents, which would upload backups and sync locks), avoids detecting sync services case by case, and prepares cloud projects (the library becomes their local copy). Projects stay plain folders in the library, because agents and the `elabora` command work on files by path; the command line still works on any folder. Archives (`<course-id>.elabora`) carry the project's files, optionally its history, and are the open-format sources delivered to clients.
*Revisit if:* testers need to keep projects in a shared drive (then cloud projects, not shared folders).
