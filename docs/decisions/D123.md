# D123. The renders reach a canvas page without a server as events of the engine, never through the relay (19 Nov 2026)

On the desktop the engine renders the screen shown and pushes it to the pages of its local server (`SessionCanvas`). A browser's engine runs in a Worker of the app and has no server: it still renders, and the window frames the page. D105 left the service `canvas` out of the browser's session; this puts it in.

Decided:
- **The browser's session announces the service `canvas` and answers `openCanvas`, `canvasView` and `closeCanvas` as the desktop's does**, with the same logic behind them (the screen shown, its state, step, layer, moment; the render made again after a change that affects it): `SessionCanvas` takes a sink, which on the desktop is the local host and in a browser is an event.
- **Two events carry what the host pushes** (`@elabora/player` `canvas-protocol.ts`): `canvasRender { id, render }`, with `render` the one the desktop's host sends its pages, made in one place (`screenRenderOf`: the screen, the course reduced to it, its view, the design layer, the files by their hash, the outline), and `canvasView { id, view }`, what `elabora/view` takes. The window gives them to the page host (`push`, `view`). `openCanvas` gives `{ url: '', base: '', token: '' }` and the view: the three words are the page's, which the engine does not know.
- **A render never goes through the relay.** It is data (text and JSON) that the window posts to the page; the relay serves the files of the module that the page asks for afterwards (images, media, fonts, an object's code).

Weighed:
- **The page asking the engine for its renders through the relay.** Rejected: the relay answers questions about files of the open module (D118), by a route; a render is made of the module's state, changes when a command does, and is pushed. Making it a file would make the relay a second channel of the engine.

*Revisit if:* a render outgrows a message (a module of hundreds of screens with its whole course in one render): then it is sent in pieces, by this event.
