# Detailed voice, dialogue, pronunciation and timing recipes

The short `elabora-narration` skill owns the consent threshold and workflow. Read this reference for exact parameters and examples.

- a voice over a slide → the screen's `narration` (`elabora_get_schema screen`): set it with `elabora_update_screen { id, narration }` (null removes it), its script as `lines` (`id`, `speaker` declared in `course.json` `speakers` with the name captions show (`elabora_update_course { speakers }`), `text` word for word, `step`, `pauseBefore`), `advance: "learner"` (or `auto`: the steps chain; `next-screen`: then the next screen comes by itself, `W_AUTO_ADVANCE`) and `seek: "seen"` by default (`course.json` `narration` sets the course's defaults). The learner's controls (seek bar, captions on by default or not, volume, transcript, speeds) are the player's `controls` item: `elabora_player { options: { controls: { … } } }`; keep the transcript and the speeds (0.75–2×) unless the author insists. Each step is a stretch of the voice: blocks with that `step` appear with it (skill `elabora-pedagogy`, narrated screens). The audio of each line comes from a generated voice or a recording (`elabora_import_narration`, `elabora narration import . <screen> <line> <file>`); until every line has its audio the screen runs silent on estimated times. A recording with no line yet makes its own (`elabora_narration_line_from_audio`: its text transcribed on this computer, punctuated, numbers in words: read it and correct the spelling); a recorded line whose recording says other words takes them (`elabora_narration_text_from_audio`, `preview: true` first when the author should choose). ElevenLabs transcribes only when the author asks (`service: "elevenlabs"`, the same share-of-quota rule as its voices). A generated voice: `elabora_voice_list` (by language: id, woman or man, register and pace, licence), `elabora_voice_set` for each speaker (`speakers[].voices[<lang>]`; distinct voices for the speakers of a dialogue), then `elabora_voice_generate { screen }` makes every line missing or out of date with its speaker's voice (`elabora voice generate . <screen>`); `lines: ["l2"]` makes another take of a line, `take` puts an earlier one back (`elabora_voice_takes`). The local voices are free and run on this computer; their model downloads once per language (fr 354 MB: `elabora_voice_install` first if a long call would time out). The credit each voice needs reaches the module credits by itself. ElevenLabs voices (the author's key and monthly quota; D29): `elabora_voice_search` (account and library, with previews to hear free), `elabora_voice_set { provider: "elevenlabs", name, settings: { model: "eleven_v4", stability } }`; direct the delivery with stage directions in square brackets inside the line's text, in its language, where it changes (`[chuchote]`, `[rit]`, `[soupire]`, `[agacé, au bord de l'explosion]`): they are never shown nor counted as words, and translators keep or adapt them; a silence is safer as « … » or a new line with `pauseBefore`. `dialogue: true` says a step's lines by several speakers as one exchange (its pauses become the lines' `pauseBefore`). Costs are said as a share of the author's monthly quota, never in credits (D30), and the threshold is the skill's (`elabora_voice_estimate` says where a script stands; a line is about 0.07 % of a Starter plan): above it `elabora_voice_generate` spends nothing and returns `needsApproval` with the estimate (`estimate.percent`); only with the author's agreement call again with `approvedPercent: N`. Events at a line: `{ "on": { "type": "timeline.reached", "at": { "line": "l2" } } }` (`edge: "end"`), `timeline.ended`, `media.ended`; actions `pause-timeline`, `play-timeline`, `play-media`, `pause-media`. A word the generated voice says wrong (an acronym, a reference) goes into `course.json` `pronunciations` (`elabora_update_course { pronunciations }`; `{ "fr": [{ "text": "P-12", "say": "pé douze" }] }`) or the line's own `pronunciations`; a line said faster or otherwise, into its `delivery` (`{ "fr": { "speed": 1.1 } }`): both make the line's audio out of date until it is generated again, and captions keep the written text. Read the result with `elabora_timeline` (`elabora timeline . <screen>`) and see a moment with `elabora_look` `at: "l2"`.
- a block that comes as the voice names it → `elabora_set_timing { block, in: { at: { "line": "l2", "word": "imprimante" }, effect: "rise" } }` (`out` takes it away; effects `fade` (default), `rise`, `slide`, `zoom`, `wipe`, `draw`, `none`, or the theme's `theme.effects`; `direction` for slide and wipe; `offset` for a delay). Anchor to the word that names the block (temporal contiguity), never to seconds on a narrated screen; a few words work (`"word": "mes collègues"`), `occurrence: 2` names a word said twice. A timed block keeps its place while it is not there, so lay the slide out with every block shown. Word anchors take real times once the line's audio is aligned (`elabora_align_narration`; generated and imported lines are aligned as they are written once the language's aligner is installed); `W_NARRATION_WORD_SWALLOWED` asks for another take (a word the author heard and ignored is left out of `elabora_validate`: leave it alone). Several contents in one place: a `stack` block whose contents each have their `in`. Keep questions and buttons on screen until playback stops for the learner (`E_ACTIVITY_LEAVES_UNANSWERED`), text long enough to be read (`W_TEXT_TOO_FAST`), effects short. Events take the same anchors (`timeline.reached` `at: { line, word }`); `seek-timeline { to }` jumps there. Check with `elabora_timeline` (timed blocks, their times and effects) and `elabora_look` `at: "l2:imprimante+0.5s"`.
- a layer explained by a voice (D62) → `layers[].narration { lines: [{ id, speaker, text, pauseBefore }], seek }` in `elabora_update_screen` (or `elabora_upsert_layer`): its own timeline from its opening, in one stretch; its blocks take `timing` anchored to its lines (`{ "line": "r2", "word": "poste" }`), or `{ "seconds": n }` from its opening when it has no narration. Events: a cue on a layer's line (`timeline.reached { at: { line: "r2", word: "réseau" } }`) is on the layer's timeline by itself; `timeline.ended { layer: "rappel" }` → `hide-layer` closes it once it has spoken; `pause-timeline`, `play-timeline` and `seek-timeline` take `layer`. The screen's timeline waits while the layer speaks. `elabora_timeline` reports each layer under its screen; the package carries its track as `narration/<screen>.<layer>.m4a`.
