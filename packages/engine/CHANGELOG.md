## 0.2.0 — 2026-11-27

### Fixed

- [b0870ee2](https://github.com/aureliendossantos/elabora-core/commit/b0870ee29fd356ce2a4098a4e34b3a98770d7b57) `create_course` can start a module from a module template or from a template's charter, its files given by the host (D124): a browser makes the same module as `elabora init --template` and `elabora projects create --charter` do on a computer. `@elabora/node` exports `templateCopy`, a template's files in a language before they are made the author's. A browser's copy sends to its team the media its host holds that a change writes.
- [fae4e279](https://github.com/aureliendossantos/elabora-core/commit/fae4e279d9e4d0c7e6f096e1f57846b345211bbd) A copy keeps its link as soon as it takes in a journal entry it has nothing to send for (a change the room gave it, or one that changed nothing): before, the link it kept named the entry before, so a browser's `keptCopies` counted a change from the room as unsent until the copy wrote again, and a copy opened again applied that change a second time. `keptCopies` counts only the copy's own changes, and `isFromRoom` is `@elabora/core`'s (`sync/copy`).
- [24c1d838](https://github.com/aureliendossantos/elabora-core/commit/24c1d838a275842bca6b1416ed77dbd171afdc62) An agent's activity line that the file watcher missed (FSEvents drops events under heavy disk activity, and Node does not say so) now shows at the session's next rescan, every 15 s by default, and never twice.
- [3080b2da](https://github.com/aureliendossantos/elabora-core/commit/3080b2da9e57936b5a1f5394b4e43bf37c659564) `ProtocolClient.close()`: when the connection to the engine goes (a module closed, the engine stopped), every request still waiting is rejected as `closed`, later requests at once, and an answer that comes after is ignored. A transport that cannot send any more rejects the request rather than leaving it waiting.
  
  A session closing (the author back home, another module opened) stops its voice jobs first: the lines said so far stay, and a line being said is no longer paid for and lost when its write meets the closed session. The close version is still taken.
- [e37c52e3](https://github.com/aureliendossantos/elabora-core/commit/e37c52e3f79c2cd09ad632c6b31ce0078b21a0fd) A browser engine forgets a relay port once its page closes the route: the page says `relay/done` on the port, the engine stops what it was answering there and keeps the port no longer, instead of holding every miniature's port until the module closes.
- [76c7e920](https://github.com/aureliendossantos/elabora-core/commit/76c7e9204cdeacfba686c60055664c72c7bee037) An undo carries what it left out through a project's server (D87): `undoes.skipped` on a submission and a placed change, what the copy's and the server's rebase left out of it added (`RebaseResult.left`, `leftByRebase`), and `journalOf(log)` to read a server's log with the core's undo rules, so that what an undo kept stays in force for a later one. An undo in a linked folder is sent alone, never with the changes after it in its batch.
- [958a9158](https://github.com/aureliendossantos/elabora-core/commit/958a915883ba6c357231e903046709fbe44fb264) A browser's miniature at rest does no work: once its screen is drawn, an animation whose rule wins over the miniature's or started by script is paused, an inline SVG's SMIL animations are paused, and a GIF, an animated PNG or WebP or an SVG that animates shown by an image is shown as one still image (one GIF and one animated SVG in a miniature cost a tenth of a processor core until now). A miniature that does not answer in time is made again after 1 s and 4 s, then its place is freed and it is tried again when its scene is refreshed. A hidden tab draws no miniature: a refresh or a place freed while it is hidden waits for the tab to be seen again, and what failed meanwhile is tried again. A screen renamed changes only its own miniature's version (`thumbRender`), not every screen's.
- [69d8ccb7](https://github.com/aureliendossantos/elabora-core/commit/69d8ccb738d3522efcc717407f821dbc1707a8e4) A narration line made in a browser ends where its sound ends: the packets an AAC encoder writes past the end (one more frame from macOS's) are dropped, and an Opus sound's start is no longer cut twice. A video master made by WebKit is labelled with the colours it holds (BT.709, limited range), so that it no longer plays washed out elsewhere.
- [4e9056ab](https://github.com/aureliendossantos/elabora-core/commit/4e9056aba81d683204389dad5e29bf81706565ca) A folder linked for one account no longer sends its changes under the session of another account signed in on the same computer: the copy asks who the session is before its first connection (`account` in the cloud options, which `cloudSessionOptions` gives from `/v1/account`), and a copy linked for another account never connects, keeps its changes and its link, is not tried again, and says `held: 'other-account'`; a session the hosting no longer knows says `held: 'signed-out'`.
- [d13a7d5c](https://github.com/aureliendossantos/elabora-core/commit/d13a7d5c5a434b427299fcc5192e0c5056e47043) The ElevenLabs key's page in a browser follows no redirect with the key, and gives back of `account` and `subscription` only the plan and its count (`SUBSCRIPTION_FIELDS`), never the account's ids or its key's preview (D136). A voice's sample is read from ElevenLabs' bucket only by a plain path (no escape, query, fragment or dot segment) or from its preview route on a host named in `PREVIEW_HOSTS`: the main one, the US one, and the data residency's of the EU, India and Singapore.
- [7bf14034](https://github.com/aureliendossantos/elabora-core/commit/7bf140347f0289afdbc632ca236d19f2794b4268) Erasing a browser's copies (`forgetCopies`) erases their databases all at once, so that it waits eight seconds at most for the pages that still hold some; a copy's Worker lets its storage go as its session closes, before it answers `close`, and `keptCopies` gives way to an erasing that starts while it reads.
  
  Reading the kept copies never makes again a database an erasing removed meanwhile (Firefox made it empty, and the next opening of that copy failed: `'meta' is not a known object store name`); a copy found in such an empty database is made again.
- [467f260d](https://github.com/aureliendossantos/elabora-core/commit/467f260d681a49f43fa42c97b2d30b6b92632163) A media file an undo brings back as it was has its probe's verdict again, so its weight's notice comes back. `elabora media to-video` refuses a file a media job is still converting to its web format.
- [0284d20b](https://github.com/aureliendossantos/elabora-core/commit/0284d20b6c914dead5e4c5c5720f1519684ba2a3) A copy whose room closes it because its session ended (4009: signed out, the device revoked, the session expired) no longer reconnects in a loop against a refusal: it keeps its changes and its link, is not tried again, even when asked, and `cloudStatus` says `held: 'signed-out'`.
- [69d8ccb7](https://github.com/aureliendossantos/elabora-core/commit/69d8ccb738d3522efcc717407f821dbc1707a8e4) A module opens and keeps what is made in a private window of Safari or Firefox, which have no private file system: its media are kept in IndexedDB (as bytes where WebKit refuses a Blob there), a master is made in memory, and a voice's takes are kept in memory for the session's life.
- [ce10d0ae](https://github.com/aureliendossantos/elabora-core/commit/ce10d0ae78d24a9523a75e720556a7afd063f5a8) A browser's models Worker sets onnxruntime-web to log its errors only: under macOS it no longer writes « Unknown CPU vendor » to the console each time a model loads.
